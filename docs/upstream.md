# 项目来源与上游同步

## 来源

1. **[Sliverkiss](https://github.com/Sliverkiss)/workbuddy2api**：原始项目，奠定了网关、账号池调度、错误分类与提示词体系（仓库已删除，链接指向作者主页）。
2. **[linguo2625469/workbuddy2api-panel](https://github.com/linguo2625469/workbuddy2api-panel)**：本仓库的直接上游，加入了 Web 管理面板、积分任务体系、请求指标等大量能力，至今仍在活跃开发。
3. **[yreidev/workbuddy2api-panel](https://github.com/yreidev/workbuddy2api-panel)**：本仓库，面板用 React + HeroUI 重写，独立维护。

本仓库定期合并 [linguo2625469/workbuddy2api-panel](https://github.com/linguo2625469/workbuddy2api-panel) 的后端改动，并把上游对旧版面板的改动移植到新面板。原始项目的设计（账号池调度、错误分类、提示词体系）原样保留。

## 相对原始项目新增的能力

| 能力 | 说明 |
|---|---|
| Web 管理面板 | 前端（`web/`，React + HeroUI）构建后经 `go:embed` 打进二进制。账号池可视化、模型锁池、账号详情、积分到期提醒与分布、批量操作、日志检索、明暗主题、手机端适配 |
| 浏览器内添加账号 | 面板里完成 OAuth 登录，凭证落盘后热加载进池，不用重启；国际版自动完成注册与激活 |
| 在线配置 | 面板直接改配置，大部分字段立即生效；写回时深合并、原子替换，保留未知键 |
| 积分任务体系 | 成长任务一键完成（17/18）、任务中心批量执行、连登兑换与抽奖、猫猫旅行、夜猫子 |
| 请求指标与归档 | 成功率、耗时、token、积分、调用来源；元数据按天归档，不记提示词与正文 |
| 首启自动生成配置 | 没有配置文件时生成推荐配置与随机 `api_key` |
| 粘性会话内容回退 | 客户端不发会话 ID 时，用系统提示词与首条消息派生会话键 |
| 余额后台刷新 | 周期刷新余额，冷却账号余额恢复自动解冻 |
| 模型能力透出 | `/v1/models` 带思考档位、积分倍率、上下文与输出上限 |
| 选号增强 | 成本分层与成本探索、快过期加权、积分保底、暂停选号、模型级限额与模型锁池 |
| 国际版与企业版 | 国际版账号路由与独立并发上限；企业版账号自动识别与额度换算；跨域负载均衡 |
| 原生工具调用标记还原 | 把以纯文本落进正文的 DeepSeek 原生工具调用还原成结构化 `tool_calls` |
| 安全加固 | 常量时间密钥比较、CSP 与安全响应头、UID 白名单防路径穿越 |
| 发布 | GHCR 镜像与五平台二进制随 `main` 自动构建 |
