# 按号代理与代理池

每个号可以走自己的代理去连官方：号绑在**代理池**上，池里分给它一个代理并固定下来，这个号发给官方的全部请求（对话、积分、签到、任务、登录、刷新令牌）都从这个代理出去。用来把号分散到不同的出口 IP，避免同一个 IP 下的号太多、被官方按 IP 成批风控（[issue #4](https://github.com/yreidev/workbuddy2api-panel/issues/4)）。

不用代理池时一切照旧：号走环境变量里的全局代理或直连，见[配置 · 出站代理](configuration.md#出站代理)。

## 概念

| 名词 | 说明 |
|---|---|
| 代理 | 一个代理地址，支持 `http://`、`https://`、`socks5://`、`socks5h://`，要认证的把用户名密码写进地址。可以起名字（账号池、请求记录里显示名字），可以设到期时间 |
| 代理池 | 号按出口分的池（和账号池页的「账号分组」是两回事，账号分组给客户端密钥划号用）。号绑在池上，池里按「绑号最少」分一个代理给它，分到以后固定不变，不轮换 |
| 单独指定 | 号也可以直接指定某个代理，盖过池的分配；池内重新均分时不动它 |
| 默认池 | 国内版、国际版各可设一个。新登录、导入的号没选池时放进默认池；没设默认池的域，新号照旧不走代理 |
| 等代理 | 号绑了池，但池里没有可用的空位（没有代理、都不通、都满了）。等代理的号不接请求、不跑定时任务，有空位后自动补上 |

服务器自己的 IP 从来不当后备：绑了池的号分不到代理就等着，代理不通就暂停，都不会退回直连。

## 上手

1. 面板左侧「代理」→「代理池」右边的「新建池」：起个名字（比如「国内」），需要的话设每个代理最多几个号、勾上「国内版新号的默认池」。
2. 「代理」一栏的「导入代理」：粘贴代理列表，选导入到哪个池，点「预览」看哪几行认不出、哪几行重复，再点「导入」。导入后网关马上测连通、查出口 IP。
3. 回到「账号池」，勾选要走代理的号 → 「绑定代理」→「绑到池」。号按绑号最少分到池里的代理，卡片上显示「代理 名字 · 出口 IP」。
4. 以后添加账号时在「代理池」里选池，登录请求本身就走分到的代理。

## 导入代理

一行一个代理，行尾可以空一格写名字，空行和 `#` 开头的行跳过。认这几种写法：

```text
socks5://用户名:密码@203.0.113.10:1080 香港1
203.0.113.11:8080
203.0.113.12:8080:用户名:密码
用户名:密码@203.0.113.13:8080
用户名:密码:203.0.113.14:8080
```

- 没写协议的行按导入时选的协议（HTTP 或 SOCKS5）。没起名字的代理，名字就是「主机:端口」。
- 预览会标出认不出的行（写明原因）和重复的行：协议、用户名、主机端口都一样就算同一个代理（只改了密码也算），和已有的代理重复、和这批前面的行重复都不导入。
- 也可以上传 txt 文件，内容追加到文本框后面。
- 这一批可以一起设到期时间，之后逐个改。
- 导入后马上测，测不通的照样导入、标「不通」。代理表上方的「删掉不可用」一键删掉所有不通和已到期的代理（要确认）。
- 「导出」下载全部代理，一行一个「地址 名字」，按池分组（`# 池：名字` 的注释行），**带密码**。这个文件能原样导回来，导回时注释行跳过，全部进导入时选的池。

单个代理在代理表上点「改」：改名字、地址、池、到期时间。地址里的密码显示成 `***`，只改主机端口时保持 `***` 就沿用原密码；改了地址会清空检测结果、马上重测。换了池，绑在上面的号跟着换池。删代理时，绑在上面的号改绑到同池别的代理，没有空位就等代理。

## 分配、上限与重新均分

- 号绑到池时，分到池里能用的、绑号最少的代理；之后一直用它，不因为别的代理空出来就换。
- 池可以设「每个代理最多几个号」，`0` 是不限。池满了，新绑进来的号等代理（卡片标「等代理」），加了代理或调高上限后自动补上。调低上限不会挪走已经绑着的号，代理表上标「超上限」。
- 池卡片上的「重新均分」：池里不是单独指定的号全部重新按绑号最少分一遍。这会改这些号的出口 IP，要确认。
- 池里还有代理时不能删池；删池时，绑着这个池在等代理的号解绑。

## 代理不通

代理有三种情况算不可用：真实请求连不上代理（连不上、代理认证失败、代理拒绝转发），健康检查不通，到期。

- 绑在不可用代理上的号**暂停选号，不罚号**：不记失败、不冷却、不降权，这次请求直接换别的号。卡片标「代理不通」或「代理到期」，账号池统计里单独一栏「因代理暂停」。定时任务（签到、保活等）也跳过这些号。
- 健康检查默认每 5 分钟一次：经代理连绑在上面的号所在域的官方对话入口，做完和真实请求一样的 TLS 握手，记下通不通和延迟。没有号的代理按池的默认域测，再没有就测国内版入口。复查通了，号马上放开。
- 连续不可用超过「连续不可用多久后改绑」（默认 30 分钟），而且同池有能用的代理，就把号改绑到同池绑号最少的那个，运行日志里记一行。单独指定的号也改绑，改完按池分配算。同池没有空位就继续等。
- 代理表上「测试」手动测一个（连通加出口 IP，测完才返回，最多 40 秒），「全部重测」在后台测全部。

间隔都在代理页底部的「代理池设置」里改，保存后马上生效。

## 到期

- 代理可以填到期时间（导入时可以整批设）。到期前几天（默认 3 天）在代理页和账号池页提醒，代理表标「N 天后到期」。
- 到期就按不可用处理，同上一节：绑在上面的号暂停，过了改绑时间同池有空位就改绑。
- 续费后把到期时间往后改，或者关掉「设到期时间」，马上恢复。

## 出口 IP

官方没有回显客户端 IP 的接口，出口 IP 只能问第三方。照 [sub2api](https://github.com/Wei-Shaw/sub2api) 的做法，经代理先查 `ip-api.com`（带国家、地区和运营商），查不到再查 `ipify`（只有 IP）。地址可以在「代理池设置」里换成自己的，一行一个，按顺序试，认 JSON（`query`、`ip` 字段）、`key=value` 行（`ip=`）和只有一个 IP 的纯文本。免费的 ip-api 只有 http，每分钟限 45 次。

- 默认每小时查一次；手动测、导入后、改了地址时也查。健康检查只测连通，不查出口。
- 代理页上方写着「没绑代理的号从哪个 IP 出去」：服务器自己的出口（或环境变量里的全局代理的出口），同样定时查。
- 代理表标出三种要留意的情况：**出口重复**（和别的代理出口 IP 一样，绑在上面的号在官方看来是同一个 IP 下的号）、**和服务器同 IP**（代理可能没起作用）、**IP 变过**（最近 24 小时出口变过，动态 IP 的代理）。悬停看详情。

## 只许走号的代理

「代理池设置」里的开关，默认关：

- **关着**：没绑代理的号照旧走服务器自己的网络（或环境变量里的全局代理）。
- **开着**：没绑代理的号不接请求、不跑定时任务，命令行工具也跳过，卡片标「没绑代理」。打开时如果有没绑的号，面板会确认一次。

新设默认池时，面板问要不要把这个域现有没绑代理的号也放进来（默认不放：放进来就换了这些号的出口 IP）。网关启动时已有的号没绑就照旧走，不会自动放进默认池。

## 风控波和 WAF 按出口分开算

用了代理池以后，号的出口 IP 各不相同，[风控波暂停](gateway.md#错误分类与账号处置)和 WAF 拦截改成按出口分开算。出口按代理的出口 IP 算（还没查到就按代理），没绑代理的号共用服务器的出口。

- **风控波**：窗口内被 `11140` 限制的号（默认 15 分钟内 2 个）都在同一个出口，只暂停这个域里这个出口下的号；分布在几个出口，才照旧暂停整个域。
- **WAF 拦截**：60 秒内同一个出口有 2 个不同的号被 WAF 403 拦下，才算这个出口被拦，这次请求不再试同出口的号；别的出口还有号就接着换，没有才止损。

没用代理池时所有号同一个出口，和原来一样。

## 添加账号、导入导出凭证

- **浏览器登录**：「添加账号」里选代理池：默认池、某个池，或「不绑代理」（开着「只许走号的代理」时不能选）。登录前先在池里占一个代理，登录请求本身就走它，登录成功后新号绑在这个代理上，弹窗里写明绑在哪个代理。
  - 池里没有可用的空位时不让登录，提示先加代理或调高上限。
  - 选了「默认池」但这个版本还没设默认池：登录走默认线路，新号不绑（开着「只许走号的代理」时要先选一个池）。
  - 重新登录已经在号池里的号，沿用原来的绑定。
- **导入 JSON**：同样可以选池。
  - 选了某个池：这批号都放进这个池，已经绑在这个池里的不动。
  - 选「默认池」：新号进这个域的默认池，已有的号沿用原来的绑定。
  - 选「不绑代理」：新号不进池，已有的号沿用原来的绑定。
  - 凭证文件顶层带 `proxy_url`（CLIProxyAPI 插件等工具的写法）的，不管选了什么，都认出这个代理单独指定给这个号：已有同一个代理就用它，没有就新建（放进选的池，没选放进这个域的默认池，再没有放进自动建的「导入的代理」池）。地址认不出来只记日志、不绑。
- **导出凭证**：绑了代理的号带上 `proxy_url`（代理的完整地址，含密码），导进别的网关时认出同一个代理。

号绑哪个代理记在号自己的凭证文件里（顶层的 `proxy` 字段），换机器时连同 `auths/` 一起搬走就行。

## 命令行工具

`signin`、`credit`、`trial` 和 `login` 读同一份代理列表和绑定，号照样走自己的代理：

| 工具 | 参数 |
|---|---|
| `signin`、`credit`、`trial` | `-proxies` 指网关的 `proxies.json`（默认 `data/proxies.json`，只读）。代理不通、在等代理、开着「只许走号的代理」却没绑的号不发请求：`signin`、`trial` 记 `SKIP`，`credit` 在 `error` 里写原因 |
| `login`（`login.sh` 原样转交） | `--pool=池名` 选池（不写 = 这个域的默认池，`--pool=-` = 不绑），`--proxies` 改代理列表的路径，`--auths` 是凭证目录（里面的号算进绑号数、守池的上限）。登录请求走分到的代理，新号绑在它上面 |

命令行工具只读 `proxies.json`，不改它，也不跑健康检查。

## 存放、备份与日志

- 代理、池、设置和检测结果存在状态文件同目录的 `proxies.json`（默认 `data/proxies.json`），权限 0600，**含代理密码**。备份时连同 `auths/`、`data/` 一起备份，见[升级、备份与停机](deployment.md#升级备份与停机)。
- 设置不在 `config.json` 里，在面板「代理」页底部改，保存后马上生效。
- 请求记录多一列代理名（账号下面的「代理 名字」），可以按代理名搜。
- 日志不打印 IP：没起名字的代理名字就是「IP:端口」，日志里的 IP 一律遮成 `<IP>`。面板里照常显示。

## 和官方客户端的差别

官方客户端只有一个全局代理，没有按号的代理。网关的不同之处（依据见[官方客户端对照 · 出站代理](official-client.md#出站代理)）：

- 绑了代理的号，国内版主入口出错后改用 HTTPDNS 地址或备用 IP 重发的请求，也经号的代理连到那个 IP，握手和 `Host` 仍是官方域名；官方钉 IP 的连接一律直连。这样号的请求不会从服务器 IP 漏出去。HTTPDNS 查询本身照旧直连。
- 不带号的请求（官方静态站点、`models.dev`）走默认线路：环境变量里的代理或直连。
- 健康检查、查出口 IP 是网关自己加的请求，官方没有。
